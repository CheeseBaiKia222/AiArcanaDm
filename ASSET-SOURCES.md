# Mosaic demo image sources

Mosaic is a standalone product with its own original artwork and fictional demo identities.

## Original artwork

The following SVG illustrations were created specifically for this Mosaic demo as original vector artwork. They do not reproduce existing tarot illustrations, logos, or artists' work. Editable, reproducible source is `assets/generate-assets.mjs`.

- `wonder-poster.svg`: typographic lavender poster, “Make room for wonder.”
- `botanical-study.svg`: sage botanical specimen print.
- `blue-hour.svg`: original imaginary album-sleeve concept.
- `soft-systems.svg`: geometric lavender design study.
- `field-notes.svg`: original prose-poem poster.
- `digital-garden.svg`: conceptual digital garden illustration.
- `moon-garden.svg`: original celestial botanical print.
- `sun-study.svg`: original architectural collage.
- `cover-world.svg`: collage of original demo artwork.
- `fallback.svg`: intentional artwork placeholder used if a remote image cannot load.
- `avatar-evelyn.svg`, `avatar-mila.svg`, `avatar-leo.svg`, `avatar-sora.svg`, `avatar-theo.svg`, `avatar-amara.svg`, `avatar-jules.svg`, `avatar-niko.svg`, `avatar-ines.svg`: original symbolic portrait illustrations. These represent fictional people and use no photographs of real individuals.

The displayed creator names are fictional demo identities. Project captions describe fictional example projects. They must not be represented as real achievements or real portfolio credentials.

## External photography

The demo loads 18 photographs directly from the Unsplash image CDN with resize parameters. All 18 listed endpoints returned HTTP 200 and an `image/jpeg` response during verification on 11 October 2026. Remote availability can change; local artwork provides a fallback.

These images are labelled “Unsplash · curated inspiration” in their source data and marked `contentOrigin: saved-inspiration`. A fictional profile is the **curator**, not a claim about who photographed the image. Individual photographers have not been independently identified; no photographer attribution is invented. Exact image endpoints are retained below and in each post's source link. The applicable general license was checked at [Unsplash License](https://unsplash.com/license). Attribution is appreciated by Unsplash, though not mandatory under its general license. This demo does not use Unsplash+ assets or the Unsplash API.
